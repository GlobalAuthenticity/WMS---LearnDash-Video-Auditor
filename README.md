# WMS---LearnDash-Video-Auditor
Audita las lecciones de LearnDash: muestra qué video de YouTube, Vimeo o Bunny tiene cada una y dónde está guardado, permite editarlo o quitarlo desde la misma tabla y exportar a CSV/Excel. Además firma los embeds de Bunny y bloquea "Marcar completado" hasta terminar el video.
